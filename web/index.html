▸ Drive Provisioningpanel reference
Step 1 · every drive · front panel
Unlock factory params, then double the carrier to 16 kHz
  1. Unlock: set C00.31 = 1107 (super-user; drive disabled).
  2. Carrier → 16 kHz: navigate to R22.38 and change 0 → 1 (×2 on the 8 kHz base).
  3. Save the params, then power-cycle the drive.
⚠ Panel-only. R22.38 (0x2022:39) is not writable over EtherCAT/SDO even after the unlock, so the provision tool can't set it. Only 8 / 16 kHz are valid - any other carrier faults (Er31.0 / Er50.1). Skip the carrier if this drive must match others still on the 8 kHz base.
Step 2 · config params · provision tool
Write the nullCAT parameter set (service stopped - the tool owns the NIC)
sudo systemctl stop nullcat-pi
sudo ./provision eth0 <slave> --fresh    # write the params, verify, store to NVRAM
# power-cycle the drive
sudo ./provision eth0 <slave> --verify    # confirm everything persisted
Writes the 18 deliberate params + both notch frequencies (7999) + baseline inertia, and stores to NVRAM only if every readback verifies. A before-state backup file is written first. Per-axis inertia (auto-ID) and notch frequency are tuned separately - they are not blind-cloned.
The values below are exactly what the provision tool writes - every one has a front-panel code, so you can key them in by hand if you'd rather not run the tool. Save to NVRAM on the panel when done.

▸ Commissioning Testsmotion cycle · vibration · sweep · song
Runs only while the loop is running, every tested axis is homed and parked, and no telemetry is streaming. Amplitudes auto-derate to each axis's stroke / velocity / acceleration budgets (derated results are flagged), the normal guard chain stays live, and a sustained following error aborts the test and re-parks. Belt axes are never tested.
